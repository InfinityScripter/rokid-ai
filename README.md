# rokid-ai

Конвейер для очков Rokid: голос/фото → расшифровка → разбор намерения →
календарь / дневник еды FatSecret / итоги дня и норма / саммари встреч.
Владелец один, интерфейс — Telegram-бот с кнопками и HTTP-инбокс для
приложения очков. Бэклог и статус — `docs/ROADMAP.md`, карта кода для
агентов — `CLAUDE.md`.

## Два режима (ROKID_MODE в .env)

- **mac** — всё на Маке: Whisper локально, оба календаря через Calendar.app.
- **vds** — бот живёт на VDS 24/7 (`/opt/rokid-ai`, systemd-юнит `rokid-ai`):
  распознавание — Gemini через OpenRouter (локальный Whisper в 1 ГБ памяти
  VDS не помещается), личный календарь — напрямую в iCloud по CalDAV
  (нужны APPLE_ID_EMAIL + APPLE_APP_PASSWORD — пароль приложения с
  appleid.apple.com), рабочий — через очередь: мостик на Маке
  (`deploy/bridge.sh`, launchd раз в минуту, ssh-туннель до инбокса VDS)
  забирает задания и пишет через Calendar.app. HTTP-инбокс слушает только
  127.0.0.1 — наружу его выводит nginx с TLS.

## Что умеет бот

Голосовое, текст или фото → намерение → действие. Всё частое — кнопками,
команды остаются для точных значений.

- **Календарь** — личные события пишутся напрямую в iCloud (CalDAV), рабочие
  уходят через очередь и мостик на Маке в корпоративный календарь; защита от
  дублей, подтверждение рабочих, отмена кнопкой и голосом («отмени последнюю
  запись»), повестка («что у меня сегодня»), место события.
- **Еда → FatSecret** — «на обед борщ и два тоста» или фото тарелки →
  карточка с продуктами из базы, порциями и калориями → «✅ Записать».
  Под карточкой «✏️ Поправить» (следующее сообщение правит карточку:
  «борщ 400 грамм, тосты убери»), приём пищи (завтрак/обед/ужин/перекус) и
  дата («📅 Это было вчера / Это сегодня»). После записи — итог за день и
  остаток до нормы.
- **Дневниковый день до 04:00 по Москве** — обед, надиктованный в полночь,
  идёт на вчера; «вчера на ужин …», «позавчера …» тоже понимает.
- **Штрихкод** — на фото упаковки код читается декодером и ищется в FatSecret
  и Open Food Facts; кнопка «🔎 Штрихкод» включает режим «только по коду»
  для следующего фото. Подробности ниже.
- **Итоги дня** — кнопка «📊 Итоги дня», `/summary` (`/summary вчера`,
  `/summary 3 сентября`) или голосом «сколько я сегодня съел», «что я ел
  вчера»: итого ккал и БЖУ, остаток до нормы, приёмы пищи с ккал по каждой
  позиции, каких приёмов не хватает. Под итогами кнопки соседних дней ◀️ ▶️,
  «📈 Неделя» и «🎯 Норма». Данные — из дневника FatSecret, так что записи
  из приложения тоже считаются.
- **Неделя** — кнопка «📈 Неделя»: итоги по дням за 7 дней, среднее, дни
  сверх нормы помечены «⚠️ +N».
- **Норма** — кнопка «🎯 Норма» (−100/+100, пресеты, убрать) или `/goal 2200`,
  с БЖУ `/goal 2200 б150 ж70 у200`, голосом «поставь норму 2200». В API
  FatSecret целей нет, норма хранится у бота.
- **Напоминания** — в 14:30 и 21:30 по Москве бот сам присылает, что
  записано и чего не хватает (вечером — полные итоги). Если бот лежал
  полдня, после подъёма шлёт только самое позднее напоминание.
- **Саммари встреч** — запись длиннее 3 минут: расшифровка частями и саммари
  (тема, главное, решения, задачи) в ответ.
- **Помощь** — кнопка «❓ Помощь» или `/help`: что умеет, быстрые действия,
  статус привязки FatSecret. Всё непонятное бот честно переспрашивает
  (заметок нет: без синхронизации с Apple они бесполезны).
- **Инбокс очков** (`src/inbox.ts`, включается заданием `INBOX_TOKEN`) —
  `/glasses/chat` (аудио + опц. фото, SSE), нативный AIUI-агент `/sse`,
  OpenAI-совместимый `/chat/completions`, повестка и «Проба зрения» для экрана
  очков. Протокол — `docs/glasses-protocol.md`.

### Кнопки

Постоянная клавиатура: `🔎 Штрихкод` · `📷 Фото еды` / `📊 Итоги дня` ·
`📈 Неделя` / `🎯 Норма` · `❓ Помощь`. Inline-кнопки под сообщениями:
карточка еды (записать/поправить/не надо, приём пищи, дата), итоги (дни,
неделя, норма), панель нормы (−100/+100, пресеты, убрать), привязка
FatSecret («🔗 Привязать FatSecret» → ссылка → PIN обычным сообщением).
Карточки с кнопками хранятся на диске и переживают перезапуск бота при
деплое.

Команды (меню «/» в Telegram): `/barcode`, `/summary`, `/goal`,
`/fatsecret_link`, `/help`, `/start`.

## Деплой на VDS

Два пути, делают одно и то же (типы → тесты → rsync → зависимости → перезапуск):

- **Автоматически** — GitHub Actions `Deploy` при каждом мерже в `main`
  (`.github/workflows/deploy.yml`). Один раз нужны секреты репозитория
  (Settings → Secrets and variables → Actions): `VPS_HOST`, `VPS_USER`,
  `VPS_SSH_KEY` (приватный ключ, чей публичный добавлен в
  `authorized_keys` на VDS) и `VPS_PORT`, если не 22. Без секретов шаги
  деплоя пропускаются, проверки идут.
- **Вручную с Мака** — `./deploy/bot.sh` (реквизиты из `~/.config/blog-app/.env`).

## Запуск

1. Секреты — в `~/.config/rokid-ai/.env` (шаблон уже там, подсказки в комментариях).
   Минимум для старта: `TELEGRAM_BOT_TOKEN` (создать бота у @BotFather),
   `OPENROUTER_API_KEY` (https://openrouter.ai/settings/keys) и
   `OWNER_TELEGRAM_ID`. Модель — `ROUTER_MODEL`, по умолчанию
   `openai/gpt-5.6-luna`.
2. Распознавание речи — локальный whisper.cpp:

   ```bash
   brew install whisper-cpp
   mkdir -p ~/.cache/whisper
   curl -L -o ~/.cache/whisper/ggml-large-v3-turbo-q5_0.bin \
     https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
   ```

   Модель `large-v3-turbo` (квантованная, ~547 МБ) — лучшая точность для
   русского при скорости уровня small. Путь — `WHISPER_MODEL_PATH` в .env.
3. `npm install && npm start`

## Еда → дневник FatSecret

**Ключи в `~/.config/rokid-ai/.env`:**

- `FATSECRET_CLIENT_ID` и `FATSECRET_CLIENT_SECRET` — OAuth 2.0 для поиска продуктов. IP сервера должен быть добавлен в белый список на [platform.fatsecret.com → IP Restrictions](https://platform.fatsecret.com).
- `FATSECRET_CONSUMER_KEY` и `FATSECRET_CONSUMER_SECRET` — OAuth 1.0 для дневника.

**Привязка аккаунта FatSecret** (один раз, токены хранятся рядом с данными бота):

1. Кнопка «🔗 Привязать FatSecret» (в «❓ Помощь» или в любом ответе, где она
   нужна) или команда `/fatsecret_link`.
2. Открой ссылку, разреши доступ, получи PIN.
3. Пришли PIN обычным сообщением (просто цифры); `/fatsecret_pin <код>` тоже работает.

**Как это работает.** Фото еды или фраза («съел тарелку борща») → бот подбирает
продукты с калориями из базы → «✅ Записать» → запись в дневник (видно в
приложении FatSecret). Подпись «powered by fatsecret» — условие их бесплатного
тарифа. Подпись к фото («творожные сливки 320 грамм») главнее оценки по снимку.

**Единицы порции.** В дневник уходят единицы порции FatSecret, а не число порций:
200 г по порции «100 g» — это `number_of_units=200`. Запись подписывается словами
владельца («говяжий фарш»), чтобы итоги и приложение читались по-русски.

**Штрихкод.** Полосы на фото декодирует zxing (WASM, без нативных зависимостей;
модель читает цифры только если декодер ничего не нашёл), дальше продукт ищется
точно по коду: сначала база FatSecret (`food.find_id_for_barcode`,
Premier-exclusive; регион у API один на запрос, поэтому страна берётся из
префикса GS1 в первых цифрах кода, потом домашний RU, потом база по умолчанию
US), затем Open Food Facts (единая мировая база) — там есть российские товары и
КБЖУ с этикетки; по названию с этикетки подбирается аналог для дневника, а
этикеточные калории показываются рядом для сверки. Бот всегда пишет, что
произошло со штрихкодом (нашла / нет в базах / не читается / нет прав Premier).
**Явный режим**: кнопка «🔎 Штрихкод», слово «штрихкод» в подписи к фото или
команда `/barcode` перед фото — разбор только по коду, без угадывания по снимку;
`/barcode 4600605030288 всю банку` — сразу цифрами. Все LLM-вызовы идут с
temperature 0, чтобы одно и то же фото давало одну и ту же карточку.

**До одобрения заявки Premier Free.** Поиск по штрихкоду в FatSecret недоступен
(бот говорит об этом и идёт в Open Food Facts). Если FatSecret отклонит запись,
подтверждённые карточки копятся в буфере и дольются автоматически (проверка при
старте и раз в час); их число видно в итогах дня.

**База продуктов американская** — поиск идёт по английским названиям, бот
переводит сам.

## Структура

- `src/bot.ts` — Telegram-бот: голос, фото, текст, кнопки, команды, панель нормы, привязка FatSecret
- `src/router.ts` — LLM-роутер намерений (tool-use через OpenRouter, схемы в zod)
- `src/stt.ts` — распознавание речи: whisper.cpp (mac) / Gemini (vds)
- `src/calendar.ts`, `src/caldav.ts`, `src/events.ts`, `src/queue.ts`,
  `src/bridge.ts` — календари: Calendar.app, iCloud CalDAV, очередь и мостик
- `src/fatsecret.ts`, `src/food.ts`, `src/food-buffer.ts`, `src/barcode.ts` — еда:
  API FatSecret (поиск, дневник, итоги по дням), подбор продуктов, буфер, штрихкоды
- `src/reminders.ts` — напоминания, итоги дня и недели по дневнику FatSecret
- `src/goal.ts` — дневная норма ккал/БЖУ (`*.goal.json`)
- `src/pending.ts` — карточки еды с кнопками и режим «штрихкод» на диске
- `src/meeting.ts` — саммари встреч: нарезка записи, расшифровка, map-reduce
- `src/inbox.ts`, `src/glasses.ts`, `src/openai-compat.ts`, `src/vision.ts` —
  HTTP-инбокс очков и его ручки
- `src/format.ts` — человекочитаемые ответы бота

Тесты — `node:test` (`npm test`), типы — `npm run ts`; работают на чистой
машине без секретов (`src/test-env.ts`), CI гоняет их на каждый PR, мерж в
`main` выкатывает на VDS.
