# Дорожная карта rokid-ai

Ревизия 2026-08-26 по коду, докам и истории коммитов. Бэклога на GitHub нет
(0 issues, 0 PR); `PLAN.md` и `etap-0.md` из README лежат в `.gitignore` и в
репозиторий не попадают — этот файл теперь единая точка плана в репо.

## Сделано

- **Этап 1 — Telegram-бот.** Голос (whisper.cpp на Маке / Gemini через
  OpenRouter на VDS), фото еды, текст → LLM-роутер намерений
  (`calendar_event`, `food_log`, `note`, `cancel_last`, `agenda`,
  `meeting_audio`), человекочитаемые ответы.
- **Этап 2 — инбокс и очки.** HTTP-инбокс: `/glasses/chat` (SSE по протоколу
  rode, таймаут 40 с, идемпотентность по `recordingId`), `/sse` (нативный
  AIUI-агент), `/inbox/audio`, `/inbox/photo`, `/agenda`, `/vision/*`,
  `/bridge/*`; rate-limit по IP, nginx TLS на VDS. Android-приложение
  `glasses-app`: запись WAV, очередь досылки, автозапуск, лента с индикатором
  записи; экспериментальные модули `vats` и `vision` (поза MoveNet,
  фит-советы).
- **Этап 3 — календари.** Личные события — напрямую в iCloud по CalDAV,
  рабочие — через очередь и мостик на Маке (launchd). Защита от дублей
  (±30 мин), подтверждение рабочих событий, отмена кнопкой и голосом
  (`cancel_last`), повестка (`agenda`), место события (location).
- **Этап 4 — еда → FatSecret.** Поиск продуктов (OAuth 2.0 + фолбэк на
  подпись OAuth 1.0 при ошибке IP-whitelist), привязка аккаунта (3-legged
  OAuth 1.0 с PIN), карточка подтверждения с кнопками, запись в дневник с
  буфером до одобрения Premier Free, разбиение составной тарелки на items,
  дата по Москве, тесты (node:test). Код готов; блокер внешний — одобрение
  заявки Premier Free (подана 2026-08-23).
