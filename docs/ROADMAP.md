# Дорожная карта rokid-ai

Ревизия 2026-09-05 по коду и истории PR. Бэклога на GitHub нет — этот файл
единая точка плана в репо (`PLAN.md`/`etap-0.md` — локальные файлы владельца).

## Сделано

- **Этап 1 — Telegram-бот.** Голос (whisper.cpp на Маке / Gemini через
  OpenRouter на VDS), фото еды, текст → LLM-роутер намерений
  (`calendar_event`, `food_log`, `food_summary`, `food_goal`, `cancel_last`,
  `agenda`, `meeting_audio`, `other`), человекочитаемые ответы.
- **Этап 2 — инбокс и очки.** HTTP-инбокс: `/glasses/chat` (SSE по протоколу
  rode, таймаут 40 с, идемпотентность по `recordingId`, статусы
  «Распознаю…/Думаю…/Смотрю на фото…», поле `image`), `/sse` (нативный
  AIUI-агент), `/inbox/audio`, `/inbox/photo`, `/agenda`, `/vision/*`,
  `/bridge/*`; rate-limit по IP, лимиты тела запроса, nginx TLS на VDS.
  Android-приложение `glasses-app`: запись WAV, очередь досылки, автозапуск,
  лента с индикатором записи; экспериментальные модули `vats` и `vision`.
- **Этап 3 — календари.** Личные события — напрямую в iCloud по CalDAV,
  рабочие — через очередь и мостик на Маке (launchd). Защита от дублей
  (±30 мин), подтверждение рабочих событий, отмена кнопкой и голосом,
  повестка, место события.
- **Этап 4 — еда → FatSecret.** Поиск продуктов (OAuth 2.0), привязка
  аккаунта (3-legged OAuth 1.0, PIN кнопкой и обычным сообщением), карточка
  с кнопками (записать / поправить / не надо, приём пищи, дата), запись в
  дневник в единицах порции FatSecret (`unitsPerServing`), буфер до
  одобрения Premier Free, разбиение составной тарелки на позиции,
  дневниковый день до 04:00 МСК, «вчера на ужин …». Карточки переживают
  перезапуск (`src/pending.ts`).
- **Этап 4.1 — штрихкоды.** Декодер zxing-wasm, контрольная сумма GTIN,
  FatSecret `food.find_id_for_barcode` с регионом из префикса GS1 → RU → US
  (Premier-exclusive, бот называет причину отказа), Open Food Facts с КБЖУ
  этикетки и подбором аналога по составу, явный режим «только по коду».
- **Этап 5 — саммари встреч.** Запись длиннее 3 минут → нарезка ffmpeg по
  5 минут → расшифровка по частям → саммари (map-reduce при длинной
  расшифровке): тема, главное, решения, задачи.
- **Этап 6 — итоги, напоминания, норма.** Итоги дня из дневника FatSecret
  (`food_entries.get`): ккал и БЖУ, приёмы пищи с ккал по позициям, чего не
  хватает; любой день (кнопки ◀️ ▶️, `/summary вчера`, «что я ел вчера»),
  неделя по `food_entries.get_month`; напоминания 14:30/21:30 МСК с
  отметками на диске; норма ккал/БЖУ (`/goal`, панель с кнопками, голосом)
  и остаток до неё в итогах, после записи и по дням недели. Заметки убраны
  как бесполезные без синхронизации с Apple.
- **Инфраструктура.** CI (`tsc` + `node:test`, 71 тест) на каждый PR,
  автодеплой на VDS при мерже в `main`, тесты без секретов
  (`src/test-env.ts`), `CLAUDE.md` для агентских сессий, еженедельная
  автономная сессия улучшений.
